# Справочник оборудования

## О проекте
Веб-приложение (PWA) — справочник шоу-оборудования для технического продакшена:
звук, свет, видео, сцена, энергетика, спецэффекты, спецсвязь.
Работает на iPhone и MacBook через браузер, устанавливается на экран «Домой».
Базу пополняют до 10 человек из команды.

- Я технический директор, программирование только начинаю вспоминать.

- Иногда оставляй мне написать кусок самому, потом проверяй.

## Стек
- HTML + CSS + чистый JavaScript, без фреймворков.
- Supabase: база (Postgres), хранилище файлов, авторизация по почте.
- Хостинг: GitHub Pages.
- Регистрация закрыта, пользователей приглашаю сам из панели Supabase.

## Таблица equipment
| Поле | Тип | Комментарий |
|---|---|---|
| name | текст | наименование, обязательное |
| manufacturer | текст | производитель |
| model | текст | модель |
| rental_price | число | цена аренды, ₽ за сутки |
| category | выбор | звук / свет / видео / сцена / энергетика / спецэффекты / спецсвязь / прочее |
| subcategory | текст | подкатегория, необязательная, свободный ввод с подсказками; без неё — подгруппа «Прочее» в конце категории |
| weight_kg | число | вес, кг |
| length_mm, width_mm, height_mm | числа | габариты Д × Ш × В, мм |
| power_w | число | потребление, Вт |
| photo_path | текст | путь к фото в хранилище Supabase |
| manual_path | текст | путь к PDF-мануалу в хранилище Supabase |
| website_url | текст | ссылка на сайт |
| created_by, created_at, updated_at | авто | кто добавил и когда менялось |

## План
1. Подготовка: аккаунты GitHub и Supabase, VS Code.
2. База: таблица, хранилище файлов, правила доступа, приглашения команде.
3. Каркас: вход, список, поиск, фильтр по категориям.
4. Карточка прибора и форма добавления с загрузкой фото и PDF.
5. Публикация на GitHub Pages, установка на телефон и Mac.
6. Потом: офлайн-кэш, сумма веса и потребления по выбранным позициям, выгрузка в Excel для смет.
